# Exemplo ARQ

Protótipo de site para engenharia residencial e casas inteligentes.

## Executar

Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript sem etapa
de build ou dependências de instalação.

## Demonstração interativa

A seção "Casa inteligente" simula os controles de iluminação sobre uma foto
local da sala. Os controles não se conectam a dispositivos reais.
